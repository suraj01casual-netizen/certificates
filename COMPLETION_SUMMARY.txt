🎯 HOW TO USE
═══════════════════════════════════════════════════════════════════════════════

ACCESS DASHBOARD:
  1. Start Django:  python manage.py runserver
  2. Login:         http://localhost:8000/auth/login/
  3. Dashboard:     http://localhost:8000/auth/dashboard/

RUN TESTS:
  python manage.py test users -v 2              (All 25 tests)
  python manage.py test users.tests_dashboard_shell -v 2  (16 dashboard tests)

VERIFY DASHBOARD:
  python verify_dashboard.py                    (Visual verification)

CHECK SYSTEM:
  python manage.py check                        (Django checks)

TEST RESPONSIVE:
  • Open Browser DevTools (F12)
  • Device Toolbar (Ctrl+Shift+M)
  • Select sizes: 1440px (desktop), 768px (tablet), 375px (mobile)
